# Duatiu Prototype

I am excited to release the first **Duatiu** game prototype.

This is **not a playable game yet**. It is a prototype designed to create profound nostalgia for anyone who used to play the 1997 Electronic Arts game **S.C.A.R.A.B.**

This prototype runs in **Unreal Engine 5** and lets you walk around remastered versions of the original game spaces, interact with some basic environmental elements, and hear some of those crazy Egyptian techno sound effects again.

## Important note about Windows and antivirus warnings

This prototype is currently distributed as a Windows installer. At this stage, the installer is **not code-signed**, which means Windows may show a warning such as:

- “Windows protected your PC”
- “Unknown publisher”
- “This app is not commonly downloaded”
- “Run anyway”

That warning does **not** mean the installer contains malware. It means the installer has not yet built a public reputation with Microsoft SmartScreen, and it does not currently have a paid code-signing certificate attached to it.

As long as you downloaded the installer directly from the official GitHub release linked above, it is the official Duatiu prototype installer.

Antivirus software should not find any actual malware issue with the installer or the game. However, because this is a large Unreal Engine 5 build from an unknown publisher, antivirus software may take a little while to scan it the first time you launch it. That may cause a delay before the game opens.

If you are uncomfortable running unsigned Windows software, I completely understand. This is an early prototype release, not a commercial product.

## What this prototype is

This project is a nostalgia-driven proof of concept.

I hired an Unreal game level designer on Fiverr named **Berkay** to remaster the old S.C.A.R.A.B. game levels in Unreal Engine 5:

https://www.fiverr.com/mbtopal

He did an amazing job.

I gave him an almost impossible challenge: take the original game levels and make them look as good as possible in Unreal Engine **without changing the game geometry in any way**.

The original Level 1 only had a little over **one thousand triangles** in the entire thing.

With excellent use of materials, textures, and lighting, Berkay did a fantastic job bringing these ancient game levels back to life. Obviously, they do not look like modern AAA game titles, but they have a cool retro feel and still feel like a great space to be in. For anyone who played the original game, they trigger a huge amount of nostalgia.

I also contracted a student named **Loup Marquez-Littringer** to set up the most basic game logic so I could present this as an actual prototype with an installer:

https://www.linkedin.com/in/loupmarquez/

He did a great job hooking up the doors, elevators, jump-pads, jump-height, dead-eye aiming, and a nice collection of sound effects. So, while this is still far from a playable game, you can interact with the environment and hear those crazy Egyptian techno sound effects that my good friend **Rob Wallace** created back in the late 1990s.

All told, I spent close to **$6,000** to get this prototype put together.

I did it primarily as a proof of concept:

Could I recreate the original game levels in a modern game engine, and would they still hold up?

The answer, I believe, is yes. Almost entirely due to the incredible work Berkay did.

## What is the future of this project?

At the moment, nothing.

This prototype was my first goal, and spending this much money just to feel nostalgia is about my limit.

Would I like to turn it into a full multiplayer game?

Hell yeah.

That has been a dream of mine for decades now. However, it would cost a lot of money to do that. A massive amount, honestly, because it is not just gameplay. There are also a lot of art requirements.

If you are an expert in working on first-person shooter multiplayer games in Unreal Engine and would like to contribute to the effort, let me know.

## Possible first milestone

If I were to continue the project, my first milestone would be:

- First playable multiplayer version
- Towers and power game implemented
- Shields implemented
- Core game loop working
  - Matchmaking
  - Three kills
  - Ghost after third death
  - Power game

Would that be fun?

Yeah. Kind of.

Not as fun as having all of the player classes, weapons, modules, power-ups, and everything else that made the original game interesting. But just having the basic core game mechanic working in a multiplayer game environment would be a start.

## Why not Horus, Sekhmet, and Anubis in the first milestone?

Because the art requirements for that are massive.

The player classes were a huge part of what made S.C.A.R.A.B. special, but recreating them properly would be a much larger project than this prototype.
